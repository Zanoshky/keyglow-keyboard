before you write

  • Search the open issues first. If yours is there, add a thumbs up or a comment.
  • Check the FAQ and troubleshooting page.
  • One problem per report makes it faster to fix.

what helps

app version
Android settings, Apps, Keyglow. The version is near the bottom of that page.
phone model
Android settings, About phone.
Android version
Android settings, About phone, Android version.
the app you typed in
Some bugs only show in one app, like a messenger or a browser.
language and layout
The language you were on, and the board, like QWERTZ.
look and theme
Match my launcher, tiled or terminal, and the theme name.
autocorrect
Off, mild, normal or strong, for typing bugs.
steps
What you did, one step per line, so we can do the same.
expected and actual
What you thought would happen, and what happened.
a picture
A screenshot or a short screen recording. Drag it into the form.

Issues on GitHub are public. A screenshot of a keyboard often shows what you typed, the chat above it and the suggestions, which can include your learned words. Before you attach one, crop or cover anything private. For a typing bug, type a test sentence instead of a real message.
